# Author notes for the IMC 2027 initial draft

This package uses only the experimental results already present in the
repository. It does not claim that any additional experiment has been run.

Before submission, the authors should resolve the following evidence and
provenance items:

1. Add country-clustered uncertainty intervals for the island/archipelagic and
   coastal-mainland Layer Agreement coefficients if those existing calculations
   become available. The present draft reports coefficients without a
   significance claim.
2. Explain why the projection-score analysis contains 219 DNS units while the
   audit contains 222 DNS units.
3. Record the exact status of the service-facing units outside the 67 island/
   archipelagic and 202 coastal-mainland groups.
4. Reconcile the 124,350 pre-audit inter-region segment count with any use of
   the locally recomputed 43,455 count. The latter is deliberately omitted from
   this draft because its persisted provenance is not available.
5. Make the paper's 80% Top-2 four-class rule the primary artifact
   classification, or rename the repository's tier-based classification.
6. The existing diameter sensitivity is A-Root-only. Do not describe it as an
   all-measurement sensitivity analysis.
7. The existing files contain no completed manual corridor audit, geolocation
   perturbation, or full catchment/propagation-speed/RTT sweep. This draft
   states those limits rather than inserting planned results.
8. Replace or verify the current Calypso citation when the intended long-paper
   bibliographic record is available.
9. A Red Sea event opening was not used because the 15% traffic estimate and
   four-month repair duration still lack a verified primary citation in the
   supplied bibliography.

For Overleaf, set IMC2027-overleaf.tex as the main document.
