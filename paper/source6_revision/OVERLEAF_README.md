# IMC 2027 initial draft: Overleaf package

Upload this ZIP as a new Overleaf project. Set `IMC2027-overleaf.tex` as the Main document, select pdfLaTeX, and use BibTeX for the bibliography.

The draft uses only experimental results already present in the repository. No new experiment was added. `AUTHOR_NOTES.md` records evidence gaps and provenance questions that must be resolved before submission; none of those unresolved items is presented as a completed result in the paper.
