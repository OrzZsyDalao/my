## 一、学习单位与适配原则

Calypso 的主线是映射推断：§2 提供物理设施、使用权与虚拟化背景；§3 从背景提炼目标、难点及已有工作的限制；§4 仅做框架总览；§5、§6 详细解释数据构造和路径推断；§7 验证；§8 展示用途。

CLASP 的主线是跨层配对测量，不是新的精确海缆映射。因此，保留“背景 → 难点 → 设计 → 证据”的功能关系，不复制 Calypso 的章节数量，也不冒认其使用权解析、内陆路径推断和运营商验证能力。我们的第二章合并承担 Calypso §2 的必要背景和 §3 的问题界定；第三章承担其 §4–§6 的方法说明功能，但重点不同。

下列映射是段落功能迁移，不是原文翻译。多对一、拆分及未迁移处明确标注。我们的段号按每章正文自然段计，标题不计；引言 I1–I9 对应中英稿 P002–P010，背景 B1–B10 对应 P011–P020。

## 五、Framework 应如何学习详略：建议，尚未改正文

### 5.1 Calypso 并不是整个方法只写一个短 Overview

- §4，p.6：两段正文与 Figure 4。第一段交代目标、两个组件、输入输出与分工；第二段导航到后文。短，是因为细节在后面。
- §5 开头，p.6：先说明 Chartbook 要提供什么，再导航数据和转换过程。
- §5.1，p.6–7：数据种类、可获取性和补充方式；说明哪些信息支撑推断。
- §5.2，p.7：第一段讲为何需要陆地数据，第二段讲两套地理表示不匹配，第三段才解释统一方法。结构是“需要 → 障碍 → 操作”。
- §5.3，p.7：先讲系统级长度为何不够，再给 unfolding 操作、输出和规模；具体例子交给 Appendix B。
- §5.4，p.7：先讲商业名称与 ASN 不匹配，再给不一致实例，最后给身份对齐方法，并明确回应 Challenge 1。
- §6.1，p.8：先讲为什么需要 AS 与国家表示对齐，然后分别解释 ASN、定位和 RTT；这些是必要输入，不被包装成全部创新。
- §6.2，p.8–9：先给图表示和搜索问题，再给直连、间接、国内连接各自的判断条件。完整算法放 Appendix C，但正文保留关键分支与假设。
- §7 验证另立章节，不夹在核心映射逻辑中。

应该学习的是：文字篇幅由“读者理解核心设计需要什么”决定；关键判断和假设留在正文，完整流程及展开实例可放补充部分。不能只截取 §4 的篇幅，就认为我们的全部方法也应压成两段。

### 5.2 当前 CLASP 各节详略判断

| 当前节 | 功能和问题 | 建议详略及理由 |
|---|---|---|
| III-A Overview | 交代输入、处理流程、输出；又重复 exposure 定义 | 简洁说明两个输出和配对约束，暴露分母指向正式定义。先让读者看到贡献，不逐项解释所有输入 |
| III-B Path Extraction | 同时包含总体、原子段、字段、fallback 和准入阈值 | 保留原子段和标签定义；字段枚举可精简。30% fallback、30 segments、10 probes、3 ASNs 决定总体，必须可见，不能当作无关实现删掉 |
| III-C Feasible Corridors | 包含 catchment、生命周期、区域和 RTT 约束 | 先讲 corridor 是什么及为何选该尺度，再讲可行性。50 km、30 km、日期、200 km/ms、5 ms、未知 RTT 处理必须保留；这些决定候选空间，不是可省略的枝节 |
| III-D Allocation | 核心权重守恒与复杂评分细节混在一起 | 优先展开“一个段一个单位、候选多不增重”的原因，再给公式。三种规则及评分构成仍须说明；AS 同时参与标签与打分的关系不能隐藏。若将完整评分参数移附录，正文需明确引用 |
| III-E Mapping Resolution | 记录纳入分布的状态及未映射部分 | 状态表足够清晰，可缩短重复解释；无候选段仍在 exposure 分母的规则必须保留 |
| III-F Paired Distributions | 最直接支撑本文贡献，却在处理细节之后才出现 | 应在 Overview 先预告此节的同总体同权重约束，在正式节集中展开。保留网络标签有向、走廊无向的语义差别，不能宣称已消除所有跨层差异来源 |
| III-G Metrics | 混合指标、排序解释、bootstrap 过程和分类阈值 | 先解释单元内和跨单元两个问题，再给指标定义。80% 阈值与连续指标同时保留。国家重采样、置换次数和种子可集中到统计检验方法段，避免打断核心解释，但不得删除 |

### 5.3 推荐的阅读顺序与段落任务

不立即变动节号，先按以下逻辑组织；后续若正式重排，须同步交叉引用和中英译稿。

1. **总览**：一段提出同一总体、每段同权重的配对原则；一段用框架图说明抽取—候选—分配—比较的关系。
2. **比较对象与纳入总体**：解释国家—测量单元；解释原子段与标签；说明候选状态及必要准入规则。
3. **物理支撑构造**：先解释区域走廊的尺度语义，再给候选筛选与不确定信息处理。
4. **候选分配和配对分布（重点）**：先讲直接计数会造成什么失配，再给一单位分配和三个口径，最后正式定义两层分布及相同分母。评分细节服务此设计，不能占据整个方法叙事。
5. **比较输出（重点）**：先讲单元内宽度/集中度变化，再讲跨单元秩关联；随后说明 exposure 的独立分母与统计检验位置。

### 5.4 必须避免的过度学习

不把 CLASP 的候选生成写成 Calypso 的已验证精确路径恢复；不把 AS-economic 支持等同于完整的租赁使用权数据库；不宣称具备其内陆推断和运营商验证。也不把“配对构造”升级为已证明物理故障独立性。重点应该是读者能够解释每个结果的分母、候选权重和比较对象。
